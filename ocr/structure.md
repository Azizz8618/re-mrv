## 4. Особенности OCR, влияющие на карту

1. Метка `DOG00110` распознаётся как `00G00110`, `00600110`, `20600110`, `D0G00110`
   (D→0/2, O→0, G→6). Аналогично `REA` → `ВЕА/ЯЕА/НЕА/Real`, `MRV` → `МЯУ/МРУ/MAV`,
   `WRI` → `WRR/WRY/WRT/WED`, `RCD` → `RCP/RCH`, `DEB` → `DER/0EB/pEB/РЕВ`.
2. Цифры в метках: 3↔5 (DOG03540 → 00605540), 0↔6↔8, 1→I/l, 7→?, финальная `C` → `c/¢/G/6`.
3. Линии-разделители из дефисов psm 6 выбрасывает (это хорошо: psm 3 приклеивает их к метке
   и ломает порядок строк, разнося колонку регистров в отдельный блок — на листингах psm 3 хуже).
4. Кириллица/латиница: B↔В, C↔С, E↔Е, H↔Н, P↔Р, O↔0, X↔Х, Y↔У, M↔М.
   Примеры: `DFB ER` → `РЕВ ER`, `ЛОЖНОЕ` → `ПОЖНОЕ`, `АВОСТ` → `АБОСТ`.

## 5. Качество OCR (оценка по стр.2 и стр.9, сверено с изображениями)

- Стр.2 (шапка + таблицы): русский текст читается на ~60–70% (заголовок «ГОЛОВНОЙ РАЗДЕЛ»
  опознан, но «ДИАНА-К71» → «дДИиИАНА-К?7»); мnemonic `LINK` → `LyNK`, `LC/BLOCK/READ`
  → «ЕС, ВЕОСК, ВЕАФ»; метки DOG и адреса искажены.
- Стр.9 (плотный листинг): порядок строк и колонки сохраняются корректно; ~70% меток
  имеют правильные цифры, но префикс DOG искажён почти всегда. Комментарии на русском
  читаются на ~40–50% («Э-60» → «9760», «В НАЧАЛЕ» → «ый А», «УСТАНОВЛЕН» → «YCTAN BE»),
  отдельные мнемоники (`UZA`→`UJ`, `ITA`→`ITS`, `UTM`→`VT™`) и числа (14→614) искажены.
- Итог: OCR пригоден для навигации, поиска по ключевым словам и созданию карты.
  Для дословной расшифровки кода требуется сверка с изображением; автоматический
  «cleanup» (замена префиксов, восстановление C на конце метки) возможен, но безопасен
  только как отдельный слой, не вместо оригинального OCR.
