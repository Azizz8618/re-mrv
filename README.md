# re-mrv — реконструкция ПО тренажёра К-71 (БЭСМ-6, МАДЛЕН)

Источник: сканы «ТРЕНАЖЕР К71 / СИСТЕМНОЕ ПРОГРАММНОЕ ОБЕСПЕЧЕНИЕ /
ТЕКСТЫ ПРОГРАММ / ЭВМ БЭСМ-6» (1986), файл `СПО_тексты.pdf` (335 стр.).
Программы написаны на автокоде/ассемблере **МАДЛЕН** (1.10.72).

## Структура репозитория

| Каталог | Содержимое |
|---------|------------|
| `docs/` | Отчёты, карта PDF, проверенные расшифровки, протоколы компиляции |
| `ocr/` | Постраничный OCR (`pNNN.txt`), сводный `ocr_all.txt`, карта `structure.md` |
| `src/` | Исходные (старые) расшифровки `dog1.txt`, `dog2.txt` |
| `scripts/` | Скрипты OCR и очистки листинга |
| `build/` | `.b6`-обёртки и листинги трансляции |

## Карта документа

- стр. 2–58 — `DOG` (головной раздел МРВ, подчинённые задачи, PROMON)
- стр. 59–101 — `MRV` (MONAR, OKNO, TABNAS, TAROYA)
- стр. 102–142 — `REA`; 143–167 — `WRI`; 168–192 — `RCD`
- стр. 193–216 — `WCD`; 217–223 — `M7B`; 224–280 — `PS`
- стр. 281–335 — `DEB` (диагностика)

Подробности — `docs/PDF_structure.md`.

## Статус расшифровки

- **Головной раздел DOG (стр. 2–3)** — `docs/dog_head.txt`, компилируется
  через `dispak` + `*assembler` **без ошибок**; исправлены 4 ошибки старой
  расшифровки `src/dog1.txt` (описание — `docs/differences.md`).
- **Модуль PS (стр. 280, `ONE`/`TWO`)** — `docs/ps280_src.txt`,
  тестовая точка входа — `docs/ps280_run.txt`; сборка и запуск без ошибок.
- **Основной модуль DOG (стр. 5–58)** — `docs/dog2_compilable.txt`
  (1890 строк): ошибки трансляции **59 → 0**, полный листинг
  `docs/dog2_listing.lst` содержит эталонное
  `ЧИСЛО ОШИБ. ОПЕРАТОРОВ 0000`. Подробности правок —
  `docs/DOG2_repair.md`.
- **MRV (стр. 59–101)** — `docs/mrv/mrv_core.txt`: расшифрованы головной
  раздел `MONAR` и блок подпрограмм печати `PRINT1…PRINT12`, `PRINTS`,
  `PRINTK` (стр.83–85, адреса сверены с таблицей символов стр.86–89).
  Компиляция — 0 ошибок. В совместной сборке с DOG эти внешние ссылки
  закрылись; остались `PRINT13…20`, `PRPR2`, `PRV*`, `SPIGUN`, `DERD`,
  `DEWR`, `RZAVAR`, `WRITED`, `RQTOCHD`, `TTOCMD` (отчёт —
  `docs/mrv/REPORT.md`).
- **PS (стр. 224–280)** — `docs/ps/ps_src.txt`: расшифрован головной
  раздел `LPS1` + подпрограмма `PS1` (стр.224–226) и модуль `ONE/TWO`
  (стр.280); оба компилируются с 0 ошибок. Диспетчеры `HD PS1–PS5` и
  `СБОР 1–5` (стр.235–279) пока не расшифрованы — границы и причины
  описаны в `docs/ps/README.md`.
- **RCD / WCD (стр. 168–216)** — `docs/rcd/`, `docs/wcd/`: расшифрованы
  и скомпилированы 6 подпрограмм (`NTABIT`, `BITTAS`, `INT`, `BITTON`,
  `INT`-выдача, `48COD`), все с 0 ошибок. Остальные страницы (REAL,
  УСТ, TABLO) пока не транскрибированы.
- **DEB (стр. 281–335)** — `docs/deb/deb_src.txt`: 560 строк, 16
  подпрограмм МАДЛЕН (стр.303–335), 0 ошибок. Стр.281–302 — Fortran
  (`SPIGUN`, `DERD`, `DEWR`, `PZ AVAR`), `*assembler` их не компилирует;
  расшифрована только шапка (`docs/deb/deb_fortran_head.txt`).
- **M7B (стр. 217–223)** — `docs/m7b/`: это не один, а четыре модуля
  (`RMTOB`, `IMTOB`, `RBTOM`, `IBTOM` — преобразование вещественных/целых
  M7000 ↔ БЭСМ-6). Все скомпилированы с 0 ошибок, сводный вариант
  `m7b_run.txt` запущен через `dispak`.
- **Совместная сборка** — `docs/dog_all.txt` (головной раздел + модуль
  `DOG`, два модуля разделены `, END ,`): компиляция и запуск через
  `dispak` без ошибок (`build/harness3*.lst`). Модуль `DOG` размещен
  по `02000`; загрузчик сообщает только об отсутствующих внешних
  подпрограммах печати (`PRINT*`, `SPIGUN`, `DERD`, `DEWR`, ...),
  которые находятся в других модулях МРВ (стр. 59–101).

## Тест связи с СМ-2

`/home/azizz/Рабочий стол/Глиссада-6/ТЕСТ_СВЯЗЬ_СМ-2.pdf` (7 стр.,
15.05.84) — МАДЛЕН-программа `TST` «ВЫДАЧА ВЕЩЕСТВЕННЫХ ЧИСЕЛ»;
проверяет передачу чисел на СМ-2 по таблицам формата
`F,ZKK,<имя>`, признак конца — пара строк `,200, ,200,`.
Расшифровано полностью: `docs/sm2_test/` (МАДЛЕН `W INT`/`PROGRAM`/`W'`
+ Fortran `PRNT`). Компиляция — 0 ошибок, запуск через `dispak -t` —
`КОНЕЦ ЗАДАЧИ`, `E50 = 0`. МРВ целиком (`docs/integration/mrv_all.txt`,
50 модулей) тоже скомпилирован (0 ошибок) и запущен без `E50`.
