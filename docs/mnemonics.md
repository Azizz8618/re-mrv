# Мнемоники МАДЛЕН на стр. 2–4 листинга DOG

Источник: `/tmp/.private/azizz/opencode/glissada/samples/p-002.png`, `p-003.png`
(STR. 2–3); стр. 4 — таблица символов/статистика, исходного кода нет.
Соответствия БЭСМ-6 — из навыка `madlen-analyzer` (SKILL.md, разд. 5).
Знак `?` означает, что точное соответствие **не установлено** — не домысливать.

## Директивы (кода не порождают)

| МАДЛЕН | Назначение | Пример из scanf-листинга |
|--------|------------|--------------------------|
| NAME   | имя программы/раздела | `DOG00110 PROGRAM : , NAME,` |
| ENTRY  | точка входа | `DOG00720 NEW DOG : ,ENTRY,` |
| LC     | размещение (location) | `LINK :LC,BLOCK,...` |
| BLOCK  | блок (группа слов) | `SH PS :LC,BLOCK,` |
| CONT   | продолжение списка/таблицы | `, CONT,READ PM,READ PS(4)` |
| BSS    | резерв памяти | `LOAD PS : , BSS ,` |
| DATA   | данные | `, DATA,` |
| TEXT   | текстовый константный блок: `8H...` = 8 символов | `DOG : , TEXT,8HDOG` |
| LOG    | восьмеричная константа | `R DOG : , LOG ,50 0000` |
| EQU    | эквивалент | `L2000 : , EQU ,1770B-FRI FO` |
| END    | конец программы | `, END ,` |

## Команды/операции

| МАДЛЕН | БЭСМ-6 (по навыку) | Назначение | Строка листинга |
|--------|--------------------|------------|-----------------|
| XTS    | ≈ СЧ (ср. XTA=СЧ)  | чтение/пересылка в аккумулятор | `, XTS ,DOG`; `, XTS ,NAME PS` |
| ATX    | ЗП                 | запись аккумулятора в память | `, ATX ,INF READ` |
| AOX    | ИЛИ                | побитовое ИЛИ с памятью | `, AOX ,READ DOG` |
| VTM    | УИА                | установка индексного регистра | `1, VTM ,-30`; `13, VTM ,LOAD PS` |
| UTC    | ? (≈ УИ / УИА)     | установка индексного регистра/счётчика | `1, UTC ,31` |
| ITA    | СЧИ                | индексный регистр → аккумулятор | `, ITA ,14` |
| ITS    | ? (ср. СЧИМ)       | работа с индексным регистром | `, ITS ,14` |
| WTC    | МОД                | установка модификатора/adress modifier | `, WTC ,NUM PS`; `, WTC ,CONT DOG` |
| ASN    | СДА                | арифметический сдвиг | `, ASN ,64-30` |
| VLM    | ЦИКЛ               | циклический переход | `1, VLM ,L` |
| UJ     | ПБ                 | безусловный переход | `, UJ ,` |
| CALL   | ≈ ПВ (VJM)         | вызов подпрограммы | `, CALL,LOAD CALL`; `, CALL,LOADCALL` |
| SET    | ? (установка)      | установка/запуск (модификаторы `1`, `5`) | `:1, SET ,R DOG`; `5, SET ,LPROMON` |
| TAPE   | ? (вывод на ленту/буфер) | запись в ленточный буфер | `, TAPE,INF READ` |

## Замечания

* Из навыка `madlen-analyzer` (разд. 5): `XTA=СЧ`, `ATI=УИ`, `ATX=ЗП`,
  `AAX=И`, `AOX=ИЛИ`, `AEX=НТЖ`, `ARX=СЛЦ`, `X-A=ВЧОБ`,
  `VTM=УИА`, `ITA=СЧИ`, `ITS=СЧИМ`, `ASN=СДА`, `WTC=МОД`,
  `NTR=РЖА`, `UJ=ПБ`, `UZA=ПО`, `U1A=ПЕ`, `VJM=ПВ`, `VLM=ЦИКЛ`,
  `VZM/VIM=ПИНО`, `MTJ=УИИ`, `UTM=СЛИА`, `WTS=МОДА`.
* `XTS`, `UTC`, `SET`, `TAPE`, `CALL` в таблице навыка отсутствуют —
  указанные соответствия для них приблизительны и требуют проверки
  по документации МАДЛЕН/листингам.
* Экстракоды на стр. 2–3 не встречаются; в объявлениях LC/BLOCK
  встречается только `READ DOG` / `READ PM` (ссылки на данные).
* Символы `=:001` (литерал), `1770B` (восьмеричная константа),
  `READ DOG`, `NAME PS`, `R PM` — имена с пробелами допустимы
  (подтверждено успешной трансляцией: таблица символов `NАМЕРS`, `RРМ`).
