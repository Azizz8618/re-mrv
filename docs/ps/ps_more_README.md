## 3. Правки и отклонения от оригинала (все зафиксированы)

1. **Однопроходный транслятор.** Метки, используемые до определения
   (`TO`, `CONT`, `EXIT1`, `L`, `L1`, `TABL DB`, `CONST` в СБОР; `IS P3`,
   `IS P6`…`ONE` в HD PS1), вынесены в начало как `EQU` с адресами из
   левой колонки листинга; повторные определения в коде сняты
   (заменены на `: , BSS ,` / `: , DATA ,` без метки).
2. **Числовые opcode `700`** (слово-константа) → директива `DATA`
   с тем же операндом; пустой операнд → `0`. Как в `docs/ps/ps_src.txt`.
3. **`4, SET ,CPS…`** (p239/ps_src) не поддерживается dispak — оставлено
   в комментарии, в код не включено.
4. **`DESK Bn :LC,BLOCK,0 BLBn,T DESKBn`** — составной операнд `0 BLBn`
   даёт «ОШИБКА В АДРЕСЕ»; заменено на `BSS` + объявления `NUM PS`,
   `A PROG`, `PERIOD` через `EQU 0` (по таблице ссылок = 00000).
5. **Исправленные мнемоники** (по результату компиляции и аналогичным
   строкам других СБОР): `ITC→ITA`, `UTA→UZA`, `UIA→UZA`, `VZM→VJM`,
   `VTA→VTM`, `ATS→ATX`, `114,→14,` (однозначный модификатор).
6. **`18B→22B`** и `7700R→7700В` в HD PS1: восьмеричная цифра `8`
   неприемлема, суффикс `R` заменён на принятый в
   `docs/dog2_compilable.txt` суффикс `В`. Это адаптация, не дословная
   транскрипция.
7. **`CALL,REST` / `CALL,FIN PRC` / `CALL,RQ TO CM` / `CALL,REST EV`** —
   dispak требует, чтобы цель CALL была не определена локально; locals
   сняты, имена `RESTX`, `REVFIN`, `RQTCM` (≤5 символов, требование
   МАДЛЕН). Внешние `ОКНО`, `REST` остаются незакрытыми — ожидаемо.
8. `SUBP` → `BSS`, `IC` → `LC`, `LOG`/`GOST` оставлены (принимаются).
9. Комментарии перенесены на `С` в позиции 0; длина строк ≤ 64.
10. В `sbor2.txt` строка `, UTM ,7` исправлена на `13, UTM ,7` —
    по PNG p250 (`13, UTM ,7`), без `13` транслятор давал
    «ОШИБКА В МОДИФИКАТОРЕ».

Все правки сделаны **только в рабочих копиях**; исходники PDF/PNG не
изменялись. Там, где прочитать opcode однозначно не удавалось, сохранён
предположительный вариант с пометкой в этом README — без домысливания
семантики.
