### Расшифровка полей

| Поле паспорта | Значение | Пояснение |
|---|---|---|
| `ПАСП` | `ЗCЗ` | зона, где хранится стандартный паспорт |
| `BBEДEH` (ВВЕДЕН) | `06.06.80` | дата введения паспорта |
| ШИФР | `113300000000` | 12 цифр |
| ИМЯ | `-DOG-` | имя задачи |
| номер записи | `0017` | порядковый номер в журнале (копия 0774) |
| `BPE` (ВРЕ) | `3` | лимит времени 3 единицы |
| `BXO` (ВХО) | `7` | адрес входа 7₈ |
| `ЛИC` (ЛИС) | `0` | лист 0 |
| `EB4` (ЕВ4) | `4` | адрес загрузки/входного вектора 4₈ |
| `<AHTИAHИC>` | `<АНТИАНИС>` | текстовый комментарий в паспорте |
| `C...` | 3 слова | константы паспорта (`С`) |
| `K...` | 5 слов | команды ввода (`К`) |
| `Б--DOG-` | — | завершающее имя/признак конца паспорта |

Значения `BPE/BXO/EB` даны в KOI-7 транслитерации (`B`=В, `P`=Р, `E`=Е,
`X`=Х). Формат полей `К`/`С` описан в
`/home/azizz/Yandex.Disk/re-dispak/docs/Dispak-sysprog-guide.md:4210-4282`
(паспорт `СС` для программы «СБОР»).

**Важно:** у этого `-DOG-` `ВХО 7`, `ВРЕ 3` — это не МРВ-программа, у которой
`PROGRAM` размещено по 01000₈, `DOG` — по 02000₈, а точка входа `NEW DOG`.

## 5. Гипотезы (без домысливания)

1. **МРВ не оформлялся как задача ДИСПАК с паспортом.** Восстановленные
   тексты — модули МАДЛЕН, трансляция через `*assembler`; загрузка идёт
   через bootstrap `eeв1а3` и колоду `.b6`, а не через `ПАСП ...` с
   `ВХО/ВРЕ/ОЗУ`. Это согласуется с README репозитория re-mrv.
2. **Паспорт мог существовать на другой машине/томе** (СМ-2, Э-60, М7000),
   которые в доступных образах дисков БЭСМ-6 не представлены.
3. **`ВХО 4000`/`ЕВ4000` в `docs/2053_passports.txt`** — адрес входа
   задач `БИАЭNЕW`/`БИАЭОLD` (строки 16-18 снимка), а не зона 4000₈
   тома 2348. См. `docs/re_glissade_findings.md:89-113`.
4. **`DOG` из паспорта 2053 и `DOG` из МРВ — разные объекты**: первый
   имеет `ВХО 7`, `ВРЕ 3`, комментарий «АНТИАНИС»; второй — модуль МРВ
   по 02000₈ с входом `NEW DOG`.

## 6. Как запускать МРВ (практический рецепт, проверенный в re-mrv)

Паспорт DISPAК для МРВ не нужен: используется колода `.b6` с МАДЛЕН-транслятором.

Исходник: `/home/azizz/Yandex.Disk/re-mrv/docs/integration/mrv_all.txt`
(50 модулей). Готовая колода:
`/home/azizz/Yandex.Disk/re-mrv/build/integration/mrv_all.b6`.

Её «паспортная» часть (дословно):

```
шифр 419999 зс5^
лен 41(2048)^
eeв1а3
*name MRVALL
*no list
*assembler
```

Запуск (уже прогонялось, `КОНЕЦ ЗАДАЧИ`, `E50 = 0`, трасса
`build/integration/mrv_all_trace.txt`):

```bash
cd /home/azizz/Yandex.Disk/re-mrv/build/integration
dispak -t mrv_all.b6 > mrv_all_trace.txt 2>&1
```

Пересборка колоды из исходника:

```bash
cd /home/azizz/Yandex.Disk/re-mrv
bash scripts/build_one.sh docs/integration/mrv_all.txt MRVALL build/integration
cd build/integration && dispak -t mrv_all.b6 > mrv_all_trace.txt 2>&1
```

Точки входа (из OCR `СПО_тексты.pdf`, стр. 4, «ТАБЛИЦА ВХОДОВ», и README):

```
PROGRAM 00000
NEWDOG  00000
```

`PROGRAM` размещается по 01000₈, `DOG` — по 02000₈.

**Для запуска на `besm6` с перфокарт** («паспорт» в виде шифра/ленты) нужно
заменить системный шифр `419999` на уникальный пользовательский (например
`123456`) и подать колоду через `vu0` по рецепту `AGENTS.md` проекта
`re-dispak` (раздел 2.0.2): запуск из каталога `OSZAGR` с
`/home/azizz/Yandex.Disk/simh/BIN/besm6 dispak.ini`, `detach vu0`,
`at vu0 <абсолютный путь к mrv_all.b6>`, затем `d 6 1`, `d 5 10`,
`set cpu req`, `go`. **Этот путь сабагентом не проверялся** — проверен только
`dispak`.
