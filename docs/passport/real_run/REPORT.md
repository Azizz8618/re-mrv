# Реальная запись МРВ на рабочий диск 2348 и запуск (18.11.2026)

## Диск и резервная копия

- Рабочий диск: `~/.besm6/2348` (тот, который dispak использует по умолчанию).
- md5 до записи: `f7425f179706c16e29ba83bfcf429877`.
- Бэкап: `~/.besm6/2348.bak-before-mrv-20261118_220221`.
- md5 после записи: `9c190e11e28cfced4f4b00371b83c998`.

Диск `~/Рабочий стол/БЭСМ-6/2348` (md5 `baa55e8e…`) не трогался.

## 1. Запись

Колода `WRITE_MRV_4000.b6` = весь `src/integration/mrv_all.txt` (8281 строка)
+ `*to perso:404000`. Комментарии `.` конвертированы в `С` (иначе
`НЕДОПУСТИМЫЙ ОПЕРАТОР`). Запуск:

```bash
BESM6_PATH="$HOME/.besm6:/usr/local/share/besm6" dispak WRITE_MRV_4000.b6
```

Результат: **0 ошибок**, `ДЛИНА LIBRARY 013 ЗОН`, `КОНЕЦ ЗАДАЧИ`.
Проверка каталога:

```bash
BESM6_PATH="$HOME/.besm6:/usr/local/share/besm6" \
  besmtool view 2348 --start=04000 --last=04000 --encoding=t
```

В зоне 4000(8) — каталог из 50 модулей МРВ: `BASOR`, `FINAL`, `DESW`,
… `DOG`, `PROGRAM`, `NEWDOG`.

## 2. Запуск

Колода `RUN_MRV_521018.b6` (шифр из паспорта ДИАНА-БАРС):

```text
шифр 521018 зс5^
лен 41(2048)^
лен 40(2348)^
eeв1а3
*name MRVALL
*no list
*perso:404000
*call PROGRAM
*end file
``````
еконец
```

Результат: баннер МОНИТОР-80, `LIBRARY ОТ 18.11.26 М1`,
`PROGRAM 03122`, `NEWDOG E 03122`, `КОНЕЦ ЗАДАЧИ`, exit=0.
Предупреждение загрузчика `МАЛО ПАМЯТИ В 53377` не фатально.

Повтор с `*call NEWDOG` и параметрами паспорта `трак 150`, `озу 32`,
`вре 3600` дал тот же результат (`NEWDOG` — entry модуля `PROGRAM`,
поэтому адрес тот же).

## Оговорки

- Это загрузка PERSO-библиотеки МРВ в зону 4000(8) диска 2348, а не
  смещение всего машинного кода на адрес 04000 в памяти: dispak не умеет
  задавать такую базу для МАДЛЕН-исходника (см. `docs/mrv_write_4000_BASE.md`).
- Подлинные тома 2074/2075 для полной колоды ДИАНА-БАРС отсутствуют;
  поэтому запуск выполнен с сокращённой колодой (без `*TAPES:671201`).
- Fortran DEB компилируется отдельно через `*system` и в эту библиотеку
  не входит.
