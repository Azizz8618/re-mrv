## 1. Методика и охват

```bash
find /home/azizz -type f -regextype posix-extended -regex '.*/2[0-9]53'
# 32 файла → 22 уникальных md5
```

Для каждого уникального образа:

```bash
BESM6_PATH=<каталог образа> besmtool pass <2053|2153|2253|2353|2453>
BESM6_PATH=<каталог образа> besmtool search <номер> '<шаблон>'
BESM6_PATH=<каталог образа> besmtool view <номер> \
    --start=$((8#<зона>)) --length=1 --encoding=k|g

**Важно:** `besmtool view --start=` принимает **десятичное** число,
а печатает адрес в **восьмеричной** системе. Например, чтобы увидеть
зону `1541₈`, нужно `--start=865` (= `8#1541`).
