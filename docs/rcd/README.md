## Компиляция

Все девять файлов собраны через `scripts/build_one.sh` (директива
`dispak *assembler`). Полные листинги (без `*no list`) подтверждают
`ЧИСЛО ОШИБ. ОПЕРАТОРОВ 0000`:

```
RCD:  81 lines -> rcd_src.b6        ЧИСЛО ОШИБ. ОПЕРАТОРОВ 0000
RCD:  68 lines -> rcd_bittas.b6     ЧИСЛО ОШИБ. ОПЕРАТОРОВ 0000
RCD:  84 lines -> rcd_int.b6        ЧИСЛО ОШИБ. ОПЕРАТОРОВ 0000
RCD:   5 lines -> rcd_bitton.b6     ЧИСЛО ОШИБ. ОПЕРАТОРОВ 0000
RCD: 102 lines -> rcd_real.b6       ЧИСЛО ОШИБ. ОПЕРАТОРОВ 0000
RCD: 127 lines -> rcd_rstreg.b6     ЧИСЛО ОШИБ. ОПЕРАТОРОВ 0000
RCD: 106 lines -> rcd_rdtab.b6      ЧИСЛО ОШИБ. ОПЕРАТОРОВ 0000
RCD:  71 lines -> rcd_r48cod.b6     ЧИСЛО ОШИБ. ОПЕРАТОРОВ 0000
RCD:  90 lines -> rcd_r16cod.b6     ЧИСЛО ОШИБ. ОПЕРАТОРОВ 0000
```

Готовые `.b6`/`.lst`: `build/rcd_more/`.

Сообщение `ОТСУТСТВУЕТ PROGRAM / СВОБОД 01000` в (*no list)-режиме —
информационное: в реконструированном тексте нет директивы ENTRY.
Полный листинг REAL подтверждает совпадение адресов с эталонной таблицей
ссылок стр.178: LOOP 0014, L 0015, L1 0022, NEXT 0024, EXIT 0031,
ADR PR 0035, AV OCT 0036, PRINT 0040, TEXT 0042.

## Исправления, внесённые при транскрипции (зафиксированы)

1. `UTA` → `YTA` (в листинге буква Y печатается как U) — подтверждено
   сверкой с p192 (600 dpi) и успешной трансляцией.
2. `UZM` → `VZM` (p191, 600 dpi: `14, VZM ,FF LOOP`).
3. `UIA` → `U1A` (p191, 600 dpi: `, U1A ,AV OCT`) — в `rcd_src.txt`
   оставлено `UIA`, т.к. ассемблером принимается оба написания.
4. `, 200 ,` → `, Z00 ,` (p192, 400 dpi: `Z00`; Z в шрифте похожа на 2).
5. Модификаторы `111`, `112`, `52` из листинга не принимаются современным
   ассемблером МАДЛЕН в dispak (макс. 14): нормализованы к `11`, `12`, `5`.
   Первоначальные значения сохранены в комментариях/отчёте.
   То же сделано в `rcd_real.txt` (`112` → `12`), `rcd_rstreg.txt`
   (`111` → `11`), `rcd_rdtab.txt` (`111` → `11`), `rcd_r16cod.txt`
   (`112` → `12`), `rcd_r48cod.txt` (`111` → `11`).
6. `8, ,` (p178/p180/p183/p186) → `, Z00 ,8` — оператор в листинге
   пуст; замена выбрана как минимальная и помечена комментарием в исходнике.
7. Добавлены объявления extern-символов `BIT`, `FF LOOP` (BSS),
   `IMTOB`, `OKHO` (SUBP) — без них трансляция давала
   «НЕОПИСАННЫЙ ИДЕНТИФИКАТОР». В новых файлах добавлены:
   `R MTOB` (SUBP) в `rcd_real.txt`, `IMTOB`/`T TW`/`T WREG M,K,Y,O`
   в `rcd_rstreg.txt`, `IMTOB`/`B6`/`TT W`/`T WDT M,K,Y,O`
   в `rcd_rdtab.txt`.
8. Метка `L1` (отдельная карта RCD00710) перенесена на следующую команду —
   отдельная строка `L1 :` отвергается ассемблером.
9. Автоматические метки листинга RCDxxxxx в исходник не включены
   (они генерируются ассемблером); сохранены только пользовательские метки.
10. Комментарные карты листинга (суффикс `C` после номера RCD, например
    RCD06550C `,CALL,OKHO`, RCD04170C…RCD04210C, RCD03190C…RCD03220C)
    в код не включены — сохранены как строки комментариев.
11. `=:0007 7777` (p173, p176) заменено на `=0007 7777` — двойной знак
    не принимается ассемблером; оригинал отмечен в комментарии.
12. В `rcd_rdtab.txt` и `rcd_r16cod.txt` хвосты модулей (TEXT/TEXT*, END)
    в доступных страницах отсутствуют — добавлены минимальные объявления
    `BSS` для недостающих символов и директива `END` (помечено в исходнике).

Исходные тексты ОС и каталог `text/` не изменялись.
