`СПО_тексты.pdf`, стр.40–41, карты `DOG21760` … `DOG22340`:
PRINT13 (`, 200`), PRINT14–16 (`, 700`), PRINT17–19 (`, 200`/`, 700`),
PRINT20 (`, 200`/`, 700`). PNG 300/600 dpi — в `png/`.

## Правки относительно авторского листинга (только для трансляции)

1. `200`, `700` → `021` — по правилу `docs/mrv/REPORT.md` §3: dispak
   отвергает коды 200 и 700 (`ОШИБКА В КОП`), 021 — гипотетическая
   замена для прохождения трансляции, не восстановление машинного кода.
2. `DOG21810`: в скане поле кода пустое (`8, ,0`); заполнено как `000`
   по аналогии с `PRINTS`/`PRINT4` в `docs/mrv/mrv_core.txt`.
3. T4/T5 из листинга не вставляются — они уже описаны в `dog_all.txt`
   (BSS, строки 165–166); иначе `ДВАЖДЫ ОПИСАННЫЙ`.
4. В `dog_all_v2.txt` удалены `PRINT13 : ,SUBP,` … `PRINT20 : ,SUBP,` —
   иначе `ДВАЖДЫ ОПИСАННЫЙ ИДЕНТИФИКАТОР`.
5. Для отдельной сборки добавлены заголовок `PRINT13M : , NAME,`
   и завершающая `, END ,` (при интеграции в DOG они убраны).

## Неоднозначности скана (оставлено как прочитано)

* `19НОДЧИНЕННОЙ` (TEXT13) — в скане первая буква читается как `Н`,
  хотя по смыслу ожидалось `ПОДЧИНЕННОЙ`.
* `18Н ВЫБРОСИТЬ МРВ. ЕГ` / `18НО УЖЕ НЕТ ИЛИ ОН Е` /
  `18НЩЕ НЕ ГОТОВ. НЕ ФА` / `14НТАЛЬНО.` (TEXT16) — в сумме даёт
  «ВЫБРОСИТЬ МРВ. ЕГО УЖЕ НЕТ ИЛИ ОН ЕЩЕ НЕ ГОТОВ. НЕ ФАТАЛЬНО.».
* `3HЗНА` (TEXT19) — прочитано по скану и tesseract (`ЗНА`); по смыслу
  здесь ожидалось окончание «…природы.».
* Счётчики `H` в строках GOST/CONT перенесены дословно, без пересчёта.

## Проверка

```
dispak build/print13/print13_full.b6   → ЧИСЛО ОШИБ. ОПЕРАТОРОВ 0000  (80 карт)
dispak build/print13/dog_all_v2_full.b6 → ЧИСЛО ОШИБ. ОПЕРАТОРОВ 0000 (1956 карт)
```

В таблице загрузчика `dog_all_v2_full.lst` строки
`ОТСУТСТВУЕТ PRINT13 … PRINT20` отсутствуют (в базовом `dog_all.lst`
они есть — все восемь). Остальные externals (PRINT1–12, PRPR2, PRV*,
SPIGUN, DERD, DEWR, RZAVAR, WRIТED, …) не изменились.
