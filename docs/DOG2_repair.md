## Оговорки

1. `,SUBP,` даёт warning загрузчика `ОТСУТСТВУЕТ <имя>` — это нормально:
   DOG — один модуль многомодульного комплекса (PROGRAM / DOG / PROMON).
2. `ОТСУТСТВУЕТ PROGRAM` при `*execute` — из строки 533 `13, UJ , .УХОД В PROGRAM`;
   подпрограмма PROGRAM не входит в этот .b6.
3. Замены `↑ → >`, `-↑-↑-↑ → ------` сделаны только для прохождения
   ассемблера dispak (символ отсутствует в его кодировке); смысловое
   содержимое диагностических текстов следует восстановить из PDF при
   необходимости.
4. `N = 10B`, `TEXT55`, `S` и часть BSS-адресов — приблизительные definition;
   для точной привязки нужно дорасшифровать хвост листинга (стр. 38–44),
   где эти метки определены в эталонном модуле.
