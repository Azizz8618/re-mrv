### Единственная правка исходного текста

В 6 модулях PS (`ps_src.txt`: ONE; `sbor1–4.txt`; `hdps1.txt`)
строка `PROGRAM : , ENTRY,` заменена комментарием:
`С ИНТЕГРАЦИЯ: ENTRY PROGRAM СНЯТ (КОНФЛИКТ С ГОЛОВНЫМ PROGRAM)`.

Причина: без этого загрузчик dispak считает стартовой программой последний
такой модуль и грузит его по 01000 вместо головного PROGRAM; в листинге
появляется `ОТСУТСТВУЕТ PROGRAM` и загружается только один модуль.
Остальные строки всех исходников сохранены без изменений (проверено diff).

В `wcd_tablo.txt` вторая `NAME`-строка начинается с `.`, поэтому
`build_one.sh` превращает её в комментарий `С`; отдельным модулем
`T TAB` не является (это свойство исходника, не правка интеграции).

## Адреса загрузчика (`build/integration/mrv_all.lst`)

Имена приведены **как в листинге dispak** (в выводе символы латиницы
подменяются похожими кириллическими: `Р`=P, `Н`=H/И, `Т`=T, `С`=C).
Все адреса восьмеричные; `C` = константа, `E` = внешний символ.

| Символ в листинге | Адрес | Примечание |
|-------------------|-------|------------|
| `РRОGRАМ` | 01000 | головной раздел DOG |
| `DОG` | 02000 | основной модуль (вкл. PRINT13–20) |
| `NЕWDОG` | E 01000 | точка входа |
| `LINК` | C 01017 | LINK |
| `SНРS`, `СНРS` | 01044, 01051 | таблицы подсистем/каналов |
| `РS*МАSН` | 01063 | маска подсистемы |
| `*DЕВАR*` | C 01067 | константа/сегмент данных |
| `FRIFО` | 01114 | флаг |
| `РRINТ8`, `РRINТ80` | 04230, E 04230 | из DOG |
| `*SУSТЕМ*` | C 04266 | сервис ОС ДИСПАК |
| `РСНАNG` | C 06000 | сервис ОС ДИСПАК |
| `INFLD` | C 10000 | из REA (READ) |
| `WRIТЕD` | 16000 | из WRI (WRITE D) |
| `ВОКНО`, `ОКНО` | 16613, E 16650 | из WRI |
| `RОТОСМD`, `ТТОСМD` | 16726, E 16773 | из WRI (ROTOCM D) |
| `RUFСОМ` | 17341 | из WRI |
| `LINЕIN`, `LINЕОUТ` | E 17341, E 17344 | из WRI |
| `МОN*IТОR` | 17207 | сервис ОС ДИСПАК |
| `РLВЕG`, `РLСLО` | 17216, 17224 | сервис ОС ДИСПАК |
| `АSАVЕ*`, `SАVЕ*НID` | 17232, 17237 | сервис ОС ДИСПАК |
| `FОR*АLL` | 17254 | сервис ОС ДИСПАК |
| `ОН*`, `ОН*1` | 17256, 17263 | сервис ОС ДИСПАК |
| `ISО/GОSТ` | 17272 | сервис ОС ДИСПАК |
| `СВОБОД` | 20023 | первая свободная ячейка |

**Важно:** загрузчик dispak включает в задачу только модули, на которые
есть ссылки `XTS`/`CALL` из PROGRAM и DOG. Остальные 48 модулей
оттранслированы (0 ошибок в полном листинге), но в память задачи не
помещены — поэтому `СВОБОД 20023`, а не суммарный объём всех модулей.
Это свойство загрузчика, а не ошибка трансляции.
