## Формат таблиц (из комментария стр. 1)

```
F,ZKK,<имя переменной>    I-1 строка
F,ZKK,<имя переменной>    I-я строка
...
:Z00,
,Z00,
```

* `F` — признак: `F=00` → передача одного целого числа из ячейки
  `<имя>`; интервал шагов задаётся кодом `КК=1:37В`.
* `F≠00` → передача массива в последовательных ячейках
  `<ИМЯ>-<ИМЯ>+F`; кодом КК задаётся интервал для всего массива,
  `F = 00:15А`, максимальная длина массива — 16 слов.
* Порядок передачи чисел на СМ-2 определяется порядком строк таблицы.
* Признак конца таблицы — пара строк `:Z00,` и `,Z00,`.

Модуль `W INT` получает описатель блока (`BLOCK` с полями
`ABLOCK, NUMPS, APROG, ATABL, LENG, CNUMB`), через `IENG` и
счётчики `CNTPC1..CNTPC4` organizes выдачу; `M` — промежуточный
буфер, `OUTFLD1..3` — буферы выдачи, `TBLFLD`/`TBLCNT` — таблицы.

## Запуск

`sm2_test_run.txt` = `sm2_program.txt` + строка
` START : , ENTRY,` после `PROGRAM : , NAME,` (без NAME перед ENTRY
транслятор выдаёт «ОТСУТСТВУЕТ ЗАГОЛОВОК ПОДПРОГРАММЫ»).

```bash
bash scripts/build_one.sh docs/sm2_test/sm2_test_run.txt SM2RUN build/sm2_test
cd build/sm2_test && dispak -t sm2_test_run.b6 > sm2_test_run_trace.out 2>&1
```

* `PROGRAM=01000`, `START=E 01000`, `OUTFLD1=C 01077`, `СВОБОД 01553`.
* Диагностика загрузчика: `ОТСУТСТВУЕТ WINT`, `ОТСУТСТВУЕТ PRNT`,
  `ОТСУТСТВУЕТ W` — внешние подпрограммы в отдельной задаче.
* Трасса: `*64`, `*70`, `*74`; **E50 не возникало**;
  завершение нормальное — `КОНЕЦ ЗАДАЧИ`, exit=0.

Joint-вариант `sm2_combined.txt` = W INT + W' + PROGRAM(ENTRY):
компилируется без ошибок, `WINT=01553`, `W=01654`, остаётся только
`ОТСУТСТВУЕТ PRNT` (Fortran-подпрограмма со стр. 6 в задачу не входит).
Прогон `dispak -t`: E50=0, `КОНЕЦ ЗАДАЧИ`, exit=0
(`sm2_combined_trace.out`).

## Правки расшифровки (все зафиксированы в исходниках)

1. Пробелы в длинных именах (`W INT`, `A TABL`, `NUM PS`,
   `ALL ERR1`, `CNT ПС1`, `OUT FLD1`, …) — артефакт печати листинга;
   в таблицах ссылок PDF имена слитные (`WINT`, `ATABL`, `NUMPS`,
   `ALLERR1`, `CNTPC1`, `OUTFLD1`, …). В исходниках использованы
   слитные формы.
2. Числовые метки с точкой (`•0`, `•24`, `•1`…`•11`, `15:`) заменены
   на `N0`, `N24`, `N1`…`N11`, `N15` (повторные `•6`/`•7` → `N6A`,
   `N7A`, `N7B`), т.к. символ `•` не проходит через транслятор.
3. По уточнённым крупным фрагментам скана исправлены мнемоники/
   операнды: `5, ATA`→`5, XTA`, `AAY`→`AAX`, `4, UTM,1`→`4, UTC,64`,
   `, VTM,14`→`14, VTM,M`, `XTA,A`→`XTA,M`, `6, UTM,1`→`6, UTM,-1`,
   `ATX,AOL`→`ATX,ABL`, `, WTC,TBL CNT-1`→`, WTC,TBLCNT-1`.
4. `BLOCK`-описатель: добавлено `:LC,` перед `BLOCK`; тексты
   комментариев вынесены в отдельные строки `С` (скобки в тексте
   после запятой давали «ОШИБКА В АДРЕСЕ»).
5. `IENG` в скане определена в таблице символов (`= 00000 00011`),
   но в тексте модуля отсутствует — добавлено
   ` IENG : , EQU ,11` (иначе «НЕОПИСАННЫЙ ИДЕНТИФИКАТОР IENG»).
6. Метка модуля `W'` (апостроф на скане) → `W`: снимает ошибку метки
   и одновременно анализирует `CALL,W` головной программы.
7. Метка `TEXT1*` сохранена (звёздочка допускается транслятором).

Счётчик ошибок: **43 → 20 → 8 → 0** (промежуточные прогоны) для
модуля W INT; модули PROGRAM и W' с первого прогона — 0 ошибок.

## Что осталось непрояснённым

* Точная комментарийная строка на стр. 1 возле `NAME` — ручная
  пометка на скане (не читается); в транскрипцию не включена.
* В GOST-строке `TEXT1*` фрагмент `СИ,'172'` прочитан по скану;
  однозначно ли там запятая и кавычки — крупный план не проясняет.
* Стр. 7 — дамп, а не текст; в исходник не включён.
* Fortran `PRNT` не компилировался (в задачу входит как внешняя
  подпрограмма); формат `O6` в `FORMAT` может быть `06`.
