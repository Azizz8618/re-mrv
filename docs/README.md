## Результаты

### 1. Головной раздел DOG (стр. 2–3) — `dog_head.txt`

Независимая транскрипция по изображениям 250–300 dpi. Компилируется
`dispak` + `*assembler` **без ошибок** (`dog_head.lst`), символы
`PROGRAM=01000`, `NEWDOG=01000`, `LINK=01017`, «СВОБОД 01770».
Диагностика `ОТСУТСТВУЕТ DOG` ожидаема — подпрограмма `DOG` находится
в отдельном модуле (стр. 5–58).

Исправлены ошибки старой расшифровки
`/home/azizz/old_dispak/re-dispak/МРВ/dog1.txt`:
- `DFS B(3)` → `DES B(3)` (карта DOG00590);
- `COM(3)` → `BCOM(3)` (DOG00610, подтверждено таблицей символов);
- `V FLD(8)` → `M FLD(8)` (DOG00620, таблица символов `MFLD`);
- восстановлена метка `R PM : , LOG ,50 0040` (DOG01180).
Мнемоника `UFT` на скане (DOG01270) транслятором отвергается;
верное чтение — `SET`.

### 2. Модуль PS (стр. 280) — `ps280_src.txt` / `ps280_run.txt`

Пробная расшифровка небольшого законченного модуля `ONE`/`TWO`.
- `ps280_src.txt` — дословная транскрипция (компилируется, но выдаёт
  `ОТСУТСТВУЕТ PROGRAM`, т.к. это подпрограмма);
- `ps280_run.txt` — с добавленной точкой входа `PROGRAM` для теста:
  компиляция **без ошибок**, выполнение завершилось нормально,
  `ONE=01000`, `PROGRAM=01000`, `TWO=01005` (`ps280_run.lst`).

### 3. Основной модуль DOG (стр. 5–58) — `dog2_compilable.txt`

Восстановленная версия старой расшифровки `src/dog2.txt`: 1890 строк,
**59 ошибок → 0**. Полный листинг `dog2_listing.lst` содержит
`ЧИСЛО ПЕРФ. 1888  ЧИСЛО ОШИБ. ОПЕРАТОРОВ 0000` — совпадает с эталоном
из PDF (стр. 44–48, «ТАБЛИЦА ССЫЛОК»). Подробный список правок,
источники восстановленных символов и гипотезы — `DOG2_repair.md`.

### 4. Совместная сборка `dog_all.txt`

`dog_head.txt` + `dog2_compilable.txt` в одной задаче; модули разделены
директивой `, END ,` (иначе возникают дублирующие определения данных).
Компиляция через `dispak` + `*assembler` — без ошибок, запуск завершается
нормально (`build/harness3_exec.lst`). Оставшиеся диагностики загрузчика
`ОТСУТСТВУЕТ PRINT* / SPIGUN / DERD / DEWR ...` ожидаемы: эти подпрограммы
описаны в модулях `MRV`/`PROMON` (стр. 59–101 скана) и пока не
транскрибированы.

## Методика сборки

```
cp <source>.txt work/ && cd work
/home/azizz/Yandex.Disk/re-dispak/testdks/build_madlen.sh <source>.txt <NAME>
```

Обёртка `.b6`: `шифр 419999 зс5^`, `лен 41(2048)^`, `eeв1а3`,
`*name NAME`, `*no list`, `*assembler`, исходник, `*execute`,
`*end file`, ``````, `еконец`.

Правила: комментарий-строка — кириллическая `С` в поз. 0; инлайн —
`.` после пробела; метки не начинаются в поз. 0; числовой модификатор
индексного регистра пишется как `13, UJ ,` с ведущим пробелом.
