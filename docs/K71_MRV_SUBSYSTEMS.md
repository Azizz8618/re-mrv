## 6. Неопределённости и расхождения (не домысливать)

1. **Онега vs Омега.** В `dog2_compilable.txt:110`
   и в OCR (`p005.txt:55`, `p034.txt:39`) — `ОНЕГА`; в сводке
   `mrv_all.txt:218` — `ОМЕГА`.
2. **ПС5.** Таблицы на 4 подсистемы (`SPS(4)`, `CPS(4)`, `NPS(4)`,
   `END PS(4)`, `PS*MASH (4)`), но в PS-диапазоне есть `HD PS5`
   и `СБОР 4` собирает данные ПС-4/5. Причина не установлена.
3. **`кк 26` / `032`/`132`.** В самих листингах МРВ мнемоники
   `032`/`132`; формулировка «кк 26» и описание КАДОПАМ/КРК приходят
   из К71.05.01.00 ТО и справочников, не из СПО_тексты.pdf.
4. **`CNT ПС1..4` vs `CNTPC1..4`.** Первое — в WCD/МРВ (`LC ,32`),
   второе — в отдельном тесте СМ-2 (адреса 0071–0074₈). Не отождествлять
   без дополнительных данных.
5. **`RZAVAR` vs `PZAVAR`.** В скане p293 — `PZAVAR >00071<`;
   в `docs/integration/README.md:107` и в сводке внешних ссылок — `RZAVAR`.
6. **TABNAS/TAROYA/MONAR/OKNO** восстановлены только частично:
   `MONAR`, PRINT* и `OKNO` как `SUBP` — в `mrv_core*`; полных
   листингов TABNAS (p97), TAROYA (p100), `HD PS2–PS5` и `LPS2–LPS5`
   в репозитории нет. Соответствующие строки таблиц даны по OCR и
   шапкам, **не по дословной транскрипции**.

## 7. Итоговая схема связей (по тексту)

```
 PROGRAM/DOG  --LINK--> READ PM / STRT PM / NUM PS / AV PS /
                        WORK PS / END PS(4) / STOP F
        |  SH PS / CH PS / NAME PS / PS*MASH  (4 ПС -> 4 машины)
        |  *DEBAR* --------------------------> DEB (SPIGUN/PZAVAR/DERD/DEWR)
        |  LOAD PS ( по NAME PS ) -----------> MRV/PROMON либо ПС
        v
 MRV/PROMON (MONAR + EVENTS/IGPLIS + OKNO + TABNAS/TAROYA)
        ^                     |
        |                     +--> READ/REA --032--> пакеты из Э-60/СМ-2
        +---- WRITE/WRI --132--> пакеты в Э-60/СМ-2 (OUT FLD1..3)
               RCD/WCD/M7B  -- перекодирование block-ов ПС
        ^
 PS (LPS1..5, HD PS1..5, СБОР 1..4, ONE/TWO)
        -- YES PS / DAT PS / NERR PS / NREG PS / END PS / AV PS -->
                                                          MRV/DOG
```

Все стрелки выше подтверждены ссылками file:line в разделах 1–5;
схема — наглядная сводка, не новый факт.
